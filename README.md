# Flightdeck

Cuadro de mando estilo *cockpit* de avión: un panel de control que presenta el
estado de la operación con la misma lógica que la cabina de un avión —
instrumentos siempre visibles, lecturas primarias grandes, alertas por
severidad y sin necesidad de navegar para saber si algo va mal.

Proyecto para **AIRBUS**.
